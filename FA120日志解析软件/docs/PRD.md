# PRD — FA120 日志解析软件

## 1. 产品概述

### 1.1 背景与目标

FA120 全自动荧光免疫分析仪在运行过程中会生成详细的运行日志，工程师和技术员需要通过这些日志诊断故障、分析时序、验证流程完整性。手动阅读原始日志效率极低，本软件旨在将其自动化解析，并以可视化方式呈现。

### 1.2 核心价值

- **降低故障诊断门槛**：将非结构化日志转换为结构化可视化界面，无需手动逐行阅读
- **提升排查效率**：快速定位报警、超时动作和缺失步骤
- **标准化流程验证**：自动对比实际执行序列与标准序列，发现遗漏动作
- **数据精度分析**：通过光栅偏差数据评估电机运动精度

### 1.3 目标用户

| 用户角色 | 使用场景 |
|---------|---------|
| 售后工程师 | 现场故障诊断，快速判断故障原因 |
| 研发工程师 | 调试新功能，验证动作时序是否符合设计 |
| 生产测试人员 | 出厂前验证仪器动作流程完整性 |
| 技术支持 | 远程分析客户发送的日志文件 |

## 2. 功能需求

### 2.1 日志解析

**FR-01 文件加载**
- 支持 .txt / .log 格式的日志文件
- 自动检测文件编码（UTF-8、GBK、GB2312、GB18030）
- 支持拖拽加载（待实现）

**FR-02 样本信息解析**
- 解析样本请求行，提取：流水号、样本 ID、架位、检测项目数、稀释倍数、开盖状态、振荡状态
- 自动推断检测模式（一步法 / 单次稀释 / 多次稀释 / 两孔稀释）
- 显示样本完成状态（测试完成 / 异常 / 未知）
- 显示安排时间与完成时间

**FR-03 动作解析**
- 解析电机动作的 Start / Finish / MOTOR 三类日志行
- 提取：动作编码（一级/二级）、部件名称、起止位置坐标、时间戳、理论光栅/实际光栅
- 计算光栅偏差（actual_raster - theory_raster）
- 支持系统预置动作（样本号 00000）与样本动作分类存储

**FR-04 报警解析**
- 解析报警码（格式：G-INJ-012、C-REA-205 等）
- 关联报警到样本号与动作编码
- 同一秒内相同报警自动去重

**FR-05 仪器信息解析**
- 提取：设备序列号、软件版本、各 MCU 固件版本、4G 模块 CCID、信号强度
- 统计：请求数、检测数、开盖数、当前安排数

### 2.2 时间轴可视化

**FR-06 时间轴展示**
- 以 X 轴表示时间（毫秒精度），Y 轴列出部件名称
- 每个动作渲染为彩色矩形块，按一级动作编码循环配色（8色）
- 显示时间轴刻度（HH:MM:SS 格式）
- 报警时刻以红色竖线标记

**FR-07 时间轴交互**
- 鼠标滚轮缩放（0.02 ~ 5 px/ms 范围）
- 水平拖拽滚动
- Y 轴部件行可拖拽排序
- 点击报警标记，自动跳转并高亮对应动作表格行

### 2.3 动作详情表格

**FR-08 层级表格**
- 父行：一级动作（动作编码 + 名称 + 总耗时）
- 子行：二级子步骤（部件、坐标、时间、光栅数据）
- 支持折叠/展开（双击父行）
- 超时动作以红色背景高亮
- 光栅偏差 ≥ 3 的子行以红色文字显示
- 关联报警的行以浅红色背景标记

**FR-09 表格列**
- 动作编码、名称、子步骤、部件、起始坐标、结束坐标、开始时间、结束时间、理论光栅、实际光栅、光栅偏差

### 2.4 报警面板

**FR-10 报警列表**
- 展示所有报警：时间、报警码、关联样本、关联动作、内容、详情
- 点击报警行跳转至时间轴对应位置并高亮动作表格

### 2.5 配置管理

**FR-11 理论时间配置**
- 维护动作知识库（theory_data.json）
- 可编辑：动作描述、显示名称、理论耗时（ms）
- 双击单元格修改，自动保存

**FR-12 电机名称别名**
- 将日志中原始部件名映射为可读显示名称
- 可增删映射条目（6 个核心部件不可删除）
- 保存到 motor_aliases.json

**FR-13 参数对比**
- 加载两台仪器的 JSON 参数文件进行对比
- 树形结构展示：系统信息 > 主板 > ADP > 电机 > 坐标 > 温控
- 红色背景：值不同；黄色背景：缺失参数
- 支持搜索过滤与备注记录

### 2.6 标准序列管理

**FR-14 标准流程学习**
- 从参考日志（通常为 0001 号样本）自动提取标准动作序列
- 按检测模式分类存储（standard_sequences.json）
- 检测文件加载时自动对比，识别缺失的一级动作

### 2.7 打包与分发

**FR-15 独立可执行文件**
- 使用 PyInstaller 打包为单一 .exe（Windows x64）
- 内置所有 JSON 配置文件，无需安装 Python 运行环境
- 支持 UPX 压缩减小体积

## 3. 非功能需求

### 3.1 性能

| 指标 | 目标值 |
|-----|-------|
| 10MB 以内日志文件加载时间 | < 3 秒 |
| UI 响应延迟 | < 100ms |
| 支持最大日志文件大小 | 50MB（目标） |

### 3.2 兼容性

- 操作系统：Windows 10 x64 及以上
- 屏幕分辨率：最小 1024×768，推荐 1920×1080
- 无需网络连接（纯本地工具）

### 3.3 可靠性

- 日志编码解析失败时给出明确错误提示，不崩溃
- 日志格式异常（缺少 Finish 行等）时跳过问题行，继续解析其他内容
- 配置文件损坏时恢复默认值

### 3.4 可用性

- 主要操作路径不超过 3 步（加载文件 → 选择样本 → 查看结果）
- 界面语言：简体中文

## 4. 数据模型

### 4.1 核心数据结构

```
SampleInfo       样本请求信息
Action           电机动作记录
Alarm            报警/错误记录
InstrumentInfo   仪器元数据
SelfCheckRecord  自检记录
UserActionRecord 用户操作记录
```

### 4.2 配置文件

| 文件 | 用途 |
|-----|-----|
| theory_data.json | 动作知识库（名称、显示名、理论时间） |
| motor_aliases.json | 部件名称别名映射 |
| standard_sequences.json | 各模式标准动作序列 |
| param_action_names.json | 参数索引名称描述 |
