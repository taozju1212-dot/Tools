## v1.0.0 — 2026-04-17

> 首次正式发布

### 核心功能
- **日志解析引擎**：支持 .txt/.log 格式，自动识别 UTF-8/GBK/GB2312/GB18030 编码
- **样本信息解析**：流水号、样本 ID、架位、检测项目、稀释倍数、状态
- **电机动作解析**：Start/Finish/MOTOR 三类日志行，提取坐标、时间戳、光栅数据
- **报警解析**：错误码关联样本与动作，同秒重复去重

### 可视化组件
- **时间轴（TimelineCanvas）**：交互式时间轴，支持缩放（0.02~5 px/ms）、拖拽、报警标记
- **动作表格（TableView）**：层级树形结构，超时/报警/光栅偏差高亮显示
- **报警面板（AlarmPanel）**：全部报警列表，点击跳转对应动作

### 配置管理
- **理论时间编辑器（TheoryTimeDialog）**：维护动作知识库，支持双击修改
- **电机别名编辑器（MotorNamesDialog）**：原始部件名 → 可读显示名映射
- **参数对比（ParamsView）**：双仪器 JSON 参数文件对比，差异高亮

### 标准流程
- **标准序列学习（StandardFlowDialog）**：从参考日志提取标准动作序列
- **完整性检查**：加载日志时自动对比，标记缺失的一级动作

### 打包分发
- PyInstaller 打包为独立 Windows EXE（无需 Python 运行环境）
- 内置全部 JSON 配置文件，开箱即用

### 技术栈
- Python 3.8+，Tkinter GUI，PyInstaller 打包
- 主程序 3510 行（fa120_log_parser.py）
- 串口调试工具 582 行（serial_assistant.py，独立工具）

## 版本号规范

采用语义化版本（SemVer）：`主版本.次版本.修订号`

- **主版本**：不兼容的重大变更（如数据结构调整、配置文件格式变更）
- **次版本**：向后兼容的新功能
- **修订号**：Bug 修复和小改动
