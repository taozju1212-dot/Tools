# 全自动工装板 — 领域词汇表

> 本文件记录项目专用术语的精确定义，供开发者和产线人员共同参考。  
> 只包含对领域专家有意义的概念，不记录实现细节。

---

## 核心术语

**工装**  
用于生产线上调试和验证步进电机、光开关、条码模块、打印机等功能的 STM32 手持/台式工具设备。不是被测产品本身，而是验证被测产品功能的辅助设备。

**点动（Jog）**  
通过物理按键（M1_U / M1_D / M2_U / M2_D）瞬时驱动步进电机正转或反转的操作。按住有效，松开立即停止。点动始终使用上次长按保存的转速，与正在编辑的草稿值无关。

**草稿值**  
在编辑界面（SPEED_EDIT / CUR_EDIT）中已修改、但尚未通过长按保存的参数值。草稿值只存在 RAM 中，不影响电机实际运行，不显示在主界面的 M1/M2 卡片上。

**已保存值**  
已通过长按 ≥ 2 s 写入内部 Flash、并在上电时加载到 RAM 和硬件的参数值。M1/M2 卡片始终显示此值；点动电机始终使用此速度。

**长按保存**  
在 SPEED_EDIT 或 CUR_EDIT 中持续按下编码器按键 ≥ 2 s 的操作，触发：写内部 Flash、更新 TIM3 ARR（PWM 频率）、通过 USART1 更新 TMC2226 IRUN，然后返回主界面。短按仅退出编辑，不写任何硬件。

**校准**  
对 OPB9000 光纤位置传感器执行的两步灵敏度配置流程：  
- STEP1：写灵敏度参数（REF/OP）到传感器，确认物理信号翻转，等待操作员移开样本管。  
- STEP2：读回已写参数，验证 AGC 和 LED 强度值（DA / GA 字段）。  
校准结果不持久存储到 MCU Flash，传感器内部自行保存。

**DA / GA**  
校准完成界面显示的两个传感器读回值：  
- DA = LED 强度（OPB9000 RR 响应 Bank1 LED 字段，10 bit 十进制）  
- GA = AGC 增益（OPB9000 RR 响应 Bank1 AGC 字段，0–3）

**O1 / O2**  
两路光电开关（光开关 1 = PB1，光开关 2 = PB9）的触发状态：  
- ✓（打勾）= 光路被遮挡（EXTI 下降沿或上电读到低电平）  
- ✗（打叉）= 光路通透（EXTI 上升沿或上电读到高电平）  
上电时主动读 GPIO 电平初始化，之后由中断实时更新。

**DO1**  
通过 PB0 控制 MOS 管的数字输出通道，由 PC13 按键每次按下执行 Toggle（按一次开，再按一次关）。不影响 OLED 界面布局，通过板载 LED1 提供视觉反馈。

**焦点**  
当前编码器指向的 OLED 界面元素（M1 / M2 / 打印 / 校准 / 扫码），以加粗边框高亮显示。上电默认焦点为 M1，顺时针旋转依次循环。

**格（Click）**  
编码器旋转的最小感知单位，对应旋钮上的 1 个物理卡槽。等于 TIM2 计数变化 4 个单位（A/B 各 15 脉冲/圈，4 倍频 = 60 计数/圈，每格 4 计数）。
