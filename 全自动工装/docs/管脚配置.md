# STM32F103C8T6 全自动工装板 — 引脚配置文档

> 与 [HARDWARE/BSP/bsp.c](../工装控制/HARDWARE/BSP/bsp.c) 严格对应。任何引脚改动必须同步本文档与 BSP。

---

## 1. 时钟配置

| 项目 | 配置 | 说明 |
|---|---|---|
| **时钟源** | HSI (内部 8MHz RC) | 原理图 PD0/PD1 未接晶振 |
| **PLL** | HSI/2 × 16 = 64MHz | HSI 接 PLL 强制除 2，PLLMUL 最大 ×16 |
| **SYSCLK / HCLK** | 64 MHz | AHB 不分频 |
| **APB1 (PCLK1)** | 32 MHz | HCLK/2，必须 ≤ 36MHz |
| **APB1 定时器时钟** | 64 MHz | APB1 预分频 ≠ 1 时自动 ×2 |
| **APB2 (PCLK2)** | 64 MHz | HCLK/1，GPIO/ADC/USART1/TIM1 |
| **ADCCLK** | 10.67 MHz | PCLK2/6，必须 ≤ 14MHz |
| **Flash 等待** | 2 WS + 预取使能 | 64MHz 必需 |

**关键代码**：[bsp.c → Bsp_Clock_Init()](../工装控制/HARDWARE/BSP/bsp.c)

> ⚠️ **HSI 精度 ±1%（25°C），工业温度下 ±2%**。当前三路 UART 全部用 HSI，9600/115200 波特率均在容差范围内，但建议长期方案补 8MHz HSE 晶振到 PD0/PD1。

## 2. 全局重映射（AFIO）

| 重映射 | 寄存器位 | 释放/占用的引脚 |
|---|---|---|
| **JTAG-Disable / SW-only** | `AFIO_MAPR.SWJ_CFG = 010b` | 释放 PA15 / PB3 / PB4 作 GPIO；保留 PA13/PA14 SWD |

> 0530 起取消 I2C1 重映射：OLED 直接使用 I2C1 默认引脚 PB6/PB7；编码器 2 已删除，TIM4 不再占用 PB6/PB7。

## 4. EXTI 外部中断总表

| EXTI 线 | 引脚 | 触发 | ISR (NVIC) | 抢占/响应优先级 | 用途 |
|:-:|:-:|:-:|---|:-:|---|
| 1  | PB1  | 下降沿 | EXTI1_IRQn       | 1 / 0 | 光开关 1 |
| 3  | PB3  | 下降沿 | EXTI3_IRQn       | 2 / 0 | M2_D 反转键 |
| 4  | PA4  | 下降沿 | EXTI4_IRQn       | 2 / 1 | M1_U 正转键 |
| 8  | PA8  | 下降沿 | EXTI9_5_IRQn     | 2 / 2 | 编码器 1 按键 |
| 9  | PB9  | 下降沿 | EXTI9_5_IRQn     | 1 / 1 | 光开关 2 |
| 11 | PA11 | 下降沿 | EXTI15_10_IRQn   | 2 / 3 | 功能按键 KEY_F2 |
| 12 | PA12 | 下降沿 | EXTI15_10_IRQn   | 2 / 3 | M1_D 反转键 |
| 13 | PC13 | 下降沿 | EXTI15_10_IRQn   | 2 / 3 | DO1 触发键 |
| 15 | PA15 | 下降沿 | EXTI15_10_IRQn   | 2 / 3 | M2_U 正转键 |

NVIC 分组：`PriorityGroup_2`（4 抢占 / 4 响应）。光开关优先级最高，按键次之。所有按键须 **10–20ms 软件消抖**。

> **EXTI 端口冲突注意**：EXTI8 已被 PA8（编码器按键）占用，PB8 的 EXTI8 不可同时启用，所以 **KEY_F1 (PB8) 改为主循环轮询**（10ms 周期 + 消抖）。同理 EXTI9 已分配给 PB9（光开关 2），PA9 是 USART1_TX 不会触发外部中断，无冲突。

## 5. 定时器配置

### TIM3 — 双路 STEP PWM

| 参数 | 值 |
|---|---|
| 时钟源 | APB1 ×2 = 64 MHz |
| 预分频 (PSC) | 63 → 计数频率 1 MHz |
| 自动重载 (ARR) | 999 (默认) → 1 kHz PWM 周期 |
| CH1 模式 | PWM1, 50% 占空 |
| CH2 模式 | PWM1, 50% 占空 |
| 输出极性 | 高 |
| 引脚 | PA6 (CH1=STEP1), PA7 (CH2=STEP2) |

**频率范围**：1 Hz（ARR=999999，超出 16-bit 需提高 PSC）~ 500 kHz（ARR=1）。
**API**：`Bsp_TIM3_Set_Step1_Freq(hz)` / `Bsp_TIM3_Set_Step2_Freq(hz)`。⚠️ 两路共用 ARR，修改一路会影响另一路；若需独立调速建议改用 TIM1 + TIM3。

### TIM2 — 编码器模式（仅 1 路）

| 参数 | 值 |
|---|---|
| 模式 | Encoder Mode 3 (TI1+TI2, 4 倍频) |
| 输入极性 | 双边沿 (Rising) |
| 输入滤波 | `ICFilter = 0xA` (fDTS/32 × 8) |
| ARR | 0xFFFF (16-bit 自然回卷) |
| PSC | 0 |
| 引脚 | PA0 (CH1=A), PA1 (CH2=B) |
| 计数读取 | `Bsp_Encoder1_Get()` |

> 0530 起去掉第二路编码器：TIM4 释放、PB6/PB7 让回 I2C1。单编码器 + KEY1 按键负责"驱动器选择 / 转速调整"两类操作（按键短按切换通道，旋转调速）。

### SysTick — 延时

| 参数 | 值 |
|---|---|
| 时钟源 | HCLK/8 = 8 MHz |
| 用途 | `delay_us()` / `delay_ms()` 软件延时 |
| 中断 | 关 (非 OS 模式) |

## 6. UART 配置

| USART | TX / RX | 模式 | 波特率 | 用途 |
|:-:|---|---|:-:|---|
| **USART1** | PA9 / – (PA10 关闭) | **单线半双工** (`AF_OD`) | 115200 | TMC2226 共享 UART，两片 IC 在同一 PDN_UART 总线 |
| **USART2** | PA2 / PA3 | 全双工 8N1 | 9600 | 条码模块 (按模块手册可改) |
| **USART3** | PB10 / PB11 | 全双工 8N1 | 9600 | 热敏打印机 |

- 三路 USART 都使能 RXNE 中断，ISR 在 [stm32f10x_it.c](../工装控制/USER/stm32f10x_it.c)。
- USART1 半双工：TX 引脚 `AF_OD` + TMC2226 内部上拉 + 外部串 1kΩ (R13)。**PA10 已配为 `AIN` 防浮空耗电**。

## 10. 初始化调用顺序（main 执行流）

```
SystemInit()                  ← 启动文件自动调用，HSE 路径被禁用→仅 8MHz HSI
main()
  └─ Bsp_Init()
       ├─ Bsp_Clock_Init()    ← 切到 64MHz / 开 AFIO / JTAG-disable / I2C remap
       ├─ Bsp_GPIO_Init()     ← 所有 GPIO 模式 + LED_Init
       ├─ Bsp_EXTI_Init()     ← 9 路 EXTI
       ├─ Bsp_TIM3_PWM_Init() ← STEP1/STEP2 默认 1kHz
       ├─ Bsp_TIM2_Encoder_Init()
       ├─ Bsp_USART1_Init(115200)
       ├─ Bsp_USART2_Init(9600)
       ├─ Bsp_USART3_Init(9600)
       ├─ Bsp_ADC1_Init()
       └─ Bsp_I2C1_Init()
  └─ delay_init()              ← 必须在 Bsp_Clock_Init 之后调用
  └─ while(1) { LED_TOGGLE(); delay_ms(500); }
```

## 11. 后续验证清单

1. SWD 烧录后用万用表测 PA13/PA14 通讯正常
2. LED1（PC14）以 1 Hz 闪烁 → 时钟与基本 GPIO 通路 OK
3. 用逻辑分析仪抓 PA6/PA7 → 看 1 kHz 方波（`Bsp_TIM3_Set_Step1_Freq(1000)`）
4. 旋转编码器 → 调试器看 `TIM2->CNT` 变化
5. 触发光开关 1/2 → 分别进入 EXTI1 / EXTI9_5 中断
6. 万用表读 PA5 电压 → `Bsp_ADC_Read_Thermistor()` 返回值与电压换算一致
7. I2C 扫描 PB6/PB7 → 找到 OLED 地址
8. USART1 (PA9) 发 TMC2226 读 IFCNT 命令 → 收到回应
9. 按各 EXTI 按键 → 进入对应 EXTI 中断；KEY_F1 (PB8) 由主循环轮询验证
10. 万用表确认 PB2 = 0V（BOOT1 接地）
