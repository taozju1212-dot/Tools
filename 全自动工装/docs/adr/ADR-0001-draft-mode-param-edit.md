# ADR-0001：参数编辑采用草稿模式，长按才写硬件

**状态**：已采纳  
**日期**：2026-05-30

---

## 背景

工装同时被操作员（产线验证）和工程师（参数调试）使用，两类用户共用同一台设备、同一套界面。在工程师调整 M1/M2 转速或电流期间，操作员可能随时按下物理点动按键驱动电机。需要明确"编辑中的值"与"电机实际执行的值"之间的关系。

## 决策

**编辑器（SPEED_EDIT / CUR_EDIT）中的修改只保留在 RAM 草稿，不立即写入任何硬件。只有编码器长按 ≥ 2 s 才同时执行：写内部 Flash + 更新 TIM3 ARR + 通过 USART1 写 TMC2226 IRUN。**

具体规则：
- 短按退出编辑：只更新 RAM 草稿，M1/M2 卡片不刷新，TIM3 ARR 不变，TMC2226 不更新。
- 长按 ≥ 2 s：写 Flash → 写 TIM3 ARR → 发 TMC2226 UART → 返回 HOME，卡片刷新。
- 点动（物理按键）始终使用 TIM3 ARR 当前值（= 上次长按保存的速度）。
- 开机从 Flash 读参数，统一初始化 TIM3 ARR 和 TMC2226 IRUN。

## 理由

1. **点动行为可预测**：操作员按住 M1_U 时，电机速度必须确定。如果编辑中的草稿值实时写 TIM3 ARR，工程师旋动编码器的同时操作员点动，电机速度会随编辑动作变化，行为不可预测且存在安全隐患。

2. **TMC2226 掉电丢寄存器**：TMC2226 的 IRUN 等寄存器断电即复位，重启必须从 Flash 重新初始化，因此"短按写 UART 但不写 Flash"没有持久意义，反而增加"UART 已写但 Flash 未更新"的不一致状态。

3. **转速和电流语义统一**：两个参数的保存时机保持一致（均为长按），操作员/工程师只需记住一条规则。

## 备选方案及否决原因

**方案：编辑时实时写 TIM3 ARR（"边改边试"）**  
否决原因：操作员可能在工程师编辑途中按下点动按键，导致电机以非预期速度运行。在混合使用场景（操作员 + 工程师）下不可接受。
