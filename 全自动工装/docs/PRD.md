# 全自动工装板 PRD v1.0

> 对应硬件：STM32F103C8T6 + 1.54" 128×64 OLED + TMC2226×2 + MZR813H + OPB9000  
> 最后更新：2026-05-30（grill 环节定稿）

---

## 1. 项目背景与用户

本工装用于产线上调试和验证步进电机、光开关、条码、打印等功能。**使用人群**：操作员（A）+ 调试工程师（B）混用同一台设备；工程师调完参数后操作员接手做常规验证动作，无单独的用户鉴权或参数锁。

## 3. 界面总体框架

OLED 128×64，统一四区版式：

```
 +-------------+----------------------+-----------+
 |  M1         |      25 °C           |   打印    |  row 0..23
 |  100 RPM    |                      +-----------+
 |  1.2 A      |                      |   校准    |
 +-------------+                      +-----------+  row 24..47
 |  M2         |                      |   扫码    |
 |  100 RPM    |   +--------+-------+ |           |
 |  0.4 A      |   | O1  ✓  | O2 ✗  | |           |  row 48..63
 +-------------+---+--------+-------+-+-----------+
```

- **左列**：M1（上）/ M2（下）卡片，各约 32×32 px，显示转速 + 电流（已保存值）。
- **右列**：打印 / 校准 / 扫码 三个等高按钮卡片（32×~21 px）。
- **中央顶**：温度，16px 字体，1 Hz 刷新。
- **中央底**：O1 ✓/✗ + O2 ✓/✗ 状态条，EXTI 即时更新。
- **中央主区**：子模式内容（设置值 / 操作状态 / 校准提示 / 扫码结果）。
- **焦点高亮**：当前编码器选中的卡片加粗边框。

**5 个可选焦点**：M1 → M2 → 打印 → 校准 → 扫码（环形，顺时针）。

## 4. 全局状态机

```
                   ┌────────────────┐
                   │  HOME          │◀──────────────┐
                   └───────┬────────┘               │
          短按选中 ─┬───────┴──┬──────────┐          │
                   ▼          ▼          ▼          │
            MOTOR_MENU    PRINT_RUN  CAL_STEP1      │
                   │       完成→HOME    │            │
             短按  │                   │KEY1 短按    │
            ┌──────┴──────┐        CAL_STEP2        │
            ▼             ▼            │            │
       SPEED_EDIT    CUR_EDIT       完成/失败→HOME   │
       长按 2s 保存 ──────────────────────────────→ HOME
       短按返回 MOTOR_MENU
                              SCAN_RUN
                              短按重新扫 / 5s无操作→HOME
```

**全局规则**
- 上电：Flash 读取 → TIM3 ARR → TMC2226 IRUN → ADC 首次采样 → PB1/PB9 读电平 → 渲染 HOME（无启动画面）。
- 任何子界面 **30 s 无操作** → 返回 HOME，丢弃草稿值。
- 4 个电机键 / DO1 键 / 光开关 EXTI / 温度采样 **全局生效**，不受当前界面影响。
- TMC2226 初始化失败静默忽略。

## 5. 旋钮编码器规范

| 动作 | 触发条件 | 行为 |
|---|---|---|
| 顺时针 1 格 | TIM2 计数变化 +4 | 焦点前移 / 数值 +1 步 |
| 逆时针 1 格 | TIM2 计数变化 −4 | 焦点后移 / 数值 −1 步 |
| 短按 | KEY1 ↓沿后 < 1.5 s ↑沿 | 进入下级 / 确认选中 |
| 长按 | KEY1 持续低电平 ≥ 2.0 s | 写 Flash + TIM3 ARR + TMC2226 IRUN，返回 HOME |
| 消抖 | 软件 10 ms | 编码器无需消抖，按键必须消抖 |

## 6. 模块详细规范

### 6.1 HOME

- M1/M2 卡显示**已保存值**（Flash 读出的 rpm 和 A）；草稿值不更新卡片。
- 上电默认焦点 **M1**。
- 光开关上电时读 PB1/PB9 电平初始化；之后 EXTI 双沿更新（↓沿=✓，↑沿=✗）；ISR 仅 set dirty flag，主循环刷 OLED。
- HOME 长按编码器无效。

### 6.2 MOTOR_MENU（M1 或 M2 短按后）

中央显示 `转速 | 电流` 两个框（旋钮切换焦点）。被选中的电机卡右上角加实心标记，提醒当前编辑对象。长按 2 s 直接返回 HOME（不触发保存）。

### 6.3 SPEED_EDIT

- 中央大字：`<rpm> RPM`。
- 旋钮±25 RPM；范围 **25–1500 RPM**，饱和不回卷。
- 短按：返回 MOTOR_MENU，**卡片不更新**（仅更新 RAM 草稿）。
- 长按 2 s：写 Flash + 写 TIM3 ARR，返回 HOME，卡片刷新。
- 点动电机始终用 TIM3 ARR 当前值（= 上次保存值）。

**PWM 频率换算**（TMC2226 8 细分，步距角 1.8°，1600 脉冲/圈）：

```
ARR + 1 = 37500 / rpm
（TIM3 计数时钟 1 MHz，PSC = 63，fCK = 64 MHz）
rpm=25 → ARR=1500；rpm=1500 → ARR=25
```

**TIM3 共用 ARR**：M1/M2 不同时运行，点动时按被驱动那路的 rpm 写 ARR，另一路处于失能状态，频率无意义。

### 6.4 CUR_EDIT

- 中央大字：`<I> A`（1 位小数）。
- 旋钮 ± 1 IRUN；范围 IRUN ∈ [0, 31]。
- 显示换算：`I = 1.35 × (IRUN + 1) / 32`。
- 短按：返回 MOTOR_MENU，**不写 TMC2226，不写 Flash**（仅更新 RAM 草稿）。
- 长按 2 s：写 Flash + 发 USART1 更新 TMC2226 IRUN，返回 HOME，卡片刷新。
  - slave_addr：M1=0，M2=1；寄存器 IHOLD_IRUN，IHOLD = IRUN/2。

### 6.5 PRINT_RUN

中央显示 `打印中`（编码器旋转 / 短按忽略）。通过 USART3 依次发送：

```
A\r\n  BB\r\n  CCC\r\n  DDDD\r\n  EEEEE\r\n
```

行间延时 50 ms。全部发送完成 → 显示 `打印完成` 1 s → 自动返回 HOME。

### 6.6 SCAN_RUN

进入后立即发 12 字节扫码命令：`02 00 01 05 00 04 11 00 00 01 10 03`（USART2，9600 8N1）。

- 收到 ≥ 1 字节后，继续等待 200 ms 帧间隔无新字节即视为结束 → **整包按 ASCII 原样显示**（中央区，最多 2 行×16 字符，超出截断+`...`）。
- 3 s 内 0 字节 → 显示 `扫码失败`。
- 结果显示后：短按 → **清空 + 立即重新扫**（连续扫模式）；5 s 无操作 → 返回 HOME。

### 6.7 CALIBRATION（OPB9000）

**通信物理层**：PB5（CAL 输出，Manchester bit-bang，位周期约 2 ms）；PB4（OUT 反馈，EXTI + 轮询）。

**CAL_STEP1（第一次短按校准）**

1. 发送 CS 命令包（等价 `## CS 0 0 0 ##`）。
2. 写 Bank2：REF=15，OP=1（反向最高灵敏度）。
3. 写 Bank2：REF=4，OP=0（正向）。
4. 等待 PB4 OUT 100 ms 内出现预期翻转。

**成功** → 中央显示：
```
成功，移开管后
再次按下按键
```
编码器锁定（旋转 / 短按忽略），KEY1 短按触发 STEP2，长按 2 s 取消返回 HOME，30 s 超时返回 HOME。

**失败** → 显示 `失败，请检查试管距离`，2 s 后返回 HOME。

**CAL_STEP2（再次按 KEY1）**

发送 RR 读请求，解析 37-bit 响应：
- Bank1：CA(1) / AGC(2) / LED(10)；Bank2：REF(4) / DS(1) / OP(1)；Bank3：EF(1)

**成功**（EF=0 且 REF/OP 与写入一致）→ 显示：
```
校准完成
DA: <LED值>   GA: <AGC值>
```
停留 3 s → 返回 HOME。

**失败**（EF=1 或不一致）→ 显示 `读取失败，移开样本后再次读取`，等待 KEY1 重试（最多 3 次）→ 返回 HOME。

### 6.8 DO1 输出

PC13 每次 ↓沿 → **Toggle PB0**（按一次开，再按一次关）。同步切换 PC14 LED1，全局生效。

### 6.9 电机点动

PA4 按住 → EN1↓、DIR1=1、TIM3_CH1 PWM 输出（以 M1 已保存 rpm）；松开 → 停 PWM、EN1↑。  
PA12 同理但 DIR1=0（M1 反转）；PA15/PB3 控制 M2。  
全局生效，不影响当前子界面。同一方向冲突（同时按正/反）以最后 ↓沿为准。

### 6.10 温度采集

ADC1_IN5，1 Hz，5 次采样取均值。v1 显示原始换算值（占位），NTC 公式后续补充。温度区始终可见，不被子界面遮挡。

### 6.11 持久化（内部 Flash）

Flash 地址：`0x0800FC00`（最后 1 页，1 KB）。

```c
typedef struct {
    uint32_t magic;       // 0xA55A1234
    uint16_t m1_rpm;      // 25..1500，步长 25
    uint8_t  m1_irun;     // 0..31
    uint8_t  _pad0;
    uint16_t m2_rpm;
    uint8_t  m2_irun;
    uint8_t  _pad1;
    uint32_t crc32;
} TuneCfg;
```

**出厂默认**（CRC 校验失败时使用）：
- M1：100 RPM，IRUN=27（≈1.18 A）
- M2：100 RPM，IRUN=9（≈0.42 A）

Flash 写入失败 → 静默返回 HOME，LED1 三连闪 1 s。

## 8. 异常处理

| 场景 | 行为 |
|---|---|
| 扫码 3 s 无响应 | 显示"扫码失败" |
| 校准 PB4 无翻转 / EF=1 | 走失败路径，最多重试 3 次 |
| Flash 写入失败 | 返回 HOME，LED1 三连闪 |
| TMC2226 UART 无回应 | 静默忽略，继续运行 |
| 同时按 M1_U + M1_D | 以最后 ↓沿为准 |
| 子界面 30 s 无操作 | 返回 HOME，草稿丢弃 |
| OLED I²C 与 ISR 并发 | ISR 仅 set flag，主循环刷新 |

## 9. OLED 渲染说明

- 控制器：SSD1306 兼容，I²C 水平寻址模式。
- 字体：中文 16×16（主显示）/ 12×12（标签），ASCII 8×16 / 6×8；点阵固化在 Flash。
- 脏区刷新：分 5 块（左 M1 / 左 M2 / 中央 / 右列 / 底栏），各块独立更新。

## 11. 验证清单

1. 上电 ≤ 2 s 出 HOME，温度 1 Hz 跳动，O1/O2 反映实际光路。
2. 旋钮 1 格 → 焦点循环 M1→M2→打印→校准→扫码→M1。
3. M1 进转速 → 顺时 4 格 → 屏幕 +100 RPM → 长按保存 → 重启后值保留。
4. 点动前后：编辑期间按 PA4，电机以**旧保存速度**运行，与草稿值无关。
5. 打印：USART3 抓包见 5 行 ABCDE。
6. 扫码：结果显示后短按立即重扫，5 s 无操作回 HOME。
7. 校准 STEP1 成功 → 移管 → KEY1 → "校准完成 DA:xxx GA:x"。
8. 校准 STEP1 失败 → 2 s 后回 HOME。
9. DO1：任意界面按 PC13 → PB0 翻转，LED1 同步。
10. Flash 写入失败模拟（GDB 写保护）→ LED1 三连闪，不崩溃。
