# 电机运动计算器 PRD

## 1. 项目背景

本项目用于开发一个面向全自动仪器运动控制设计的桌面计算工具。工具主要服务于系统工程师、运动控制工程师、嵌入式工程师和调试人员，用于在仪器时序设计、运动轴选型、TMC5240 参数配置前，快速计算步进电机在不同距离、速度、加速度条件下的运动时间和寄存器参数。

当前全自动仪器中常见的运动需求包括：

- 多个运动轴需要在不同距离下评估运行时间。
- 同一距离需要比较多组速度、加速度、减速度组合。
- 需要判断短距离运动是否能达到设定最大速度。
- 需要将物理速度、加速度换算为 TMC5240 的 `VMAX`、`AMAX`、`DMAX` 等寄存器值。
- 需要将计算结果保存到 Excel，用于仪器动作时序设计和方案评审。

第一版产品不直接连接硬件，不直接写入 TMC5240，只作为工程计算、参数对比和配置参考工具。

## 2. 产品目标

### 2.1 核心目标

开发一个桌面版电机运动计算器，支持用户新建运动轴、配置电机与机构参数、输入多个运动距离和多组速度/加减速度组合，自动计算运动时间、速度曲线类型和 TMC5240 相关寄存器参考值。

### 2.2 主要价值

- 帮助系统工程师快速评估全自动仪器动作节拍。
- 帮助固件工程师将物理运动参数换算为 TMC5240 寄存器配置。
- 帮助机械和电控工程师比较不同机构参数下的运动性能。
- 替代手工 Excel 计算，减少单位换算、短距离曲线判断和寄存器换算失误。

## 3. 目标用户

- 系统工程师：关注整机节拍、动作时序和不同运动距离的总时间。
- 嵌入式工程师：关注 TMC5240 寄存器配置、速度单位换算和边界检查。
- 电控工程师：关注电机转速、步进频率、微步数和驱动参数。
- 机械工程师：关注不同机构形态下的物理速度、加速度和位移关系。
- 调试人员：关注多组参数对比、导入导出和可复现实验记录。

## 5. 核心概念

### 5.1 运动轴

运动轴是计算的基本对象。每个运动轴包含：

- 轴名称
- 轴类型
- 电机参数
- 机构参数
- 单位换算参数
- TMC5240 时钟参数
- 一组或多组运动距离
- 每个距离下的一组或多组运动参数

### 5.2 运动距离

同一轴可以配置多个运动距离。例如：

- `5 mm`
- `10 mm`
- `20 mm`
- `50 mm`
- `100 mm`

每个距离可以配置多组速度、加速度、减速度组合，用于对比不同参数下的运行时间。

### 5.3 运动参数组合

每组运动参数至少包含：

- 最大速度 `Vmax`
- 加速度 `Acc`
- 减速度 `Dec`
- 初速度 `Vstart`
- 末速度 `Vend`
- 备注

默认值：

- 初速度 `Vstart = 0 mm/s`
- 末速度 `Vend = 0 mm/s`

用户可以修改初速度和末速度，用于覆盖连续运动、非零启动速度或非零结束速度的场景。

### 5.4 T 型速度曲线

T 型速度曲线指三段式运动：

1. 加速阶段
2. 匀速阶段
3. 减速阶段

当距离足够达到最大速度时，使用 T 型，也可称为梯形速度曲线。

当距离太短，无法达到设定最大速度时，系统自动切换为三角速度曲线：

1. 加速阶段
2. 减速阶段
3. 无匀速阶段

## 7. 电机结构配置

用户新建运动轴时，需要选择电机结构形态。

### 7.1 步进旋转电机直线运动

适用于皮带、同步带、齿轮齿条等直线机构。

输入参数：

- 电机步距角，单位 `degree`
- 微步细分
- 减速比
- 主动轮齿数
- 主动轮齿距，单位 `mm`

计算目标：

- 电机每圈微步数
- 输出端每圈位移
- 每毫米微步数 `microsteps/mm`
- 物理速度与步进频率的换算

### 7.2 步进旋转电机旋转运动

适用于旋转轴。

输入参数：

- 电机步距角，单位 `degree`
- 微步细分
- 减速比

计算目标：

- 电机端转速 `rps/rpm`
- 输出端转速 `rps/rpm`
- 输出端角速度
- 输出端角位移

### 7.3 步进丝杆电机直线运动

适用于丝杆直线模组或步进丝杆电机。

输入参数：

- 电机步距角，单位 `degree`
- 微步细分
- 减速比
- 丝杆导程，单位 `mm/rev`

计算目标：

- 每圈位移
- 每毫米微步数 `microsteps/mm`
- 物理速度 `mm/s`
- 物理加速度 `mm/s²`

### 7.4 自定义换算

为兼容已知机构或已有标定结果，系统必须支持用户直接输入：

- `microsteps/mm`
- 或 `steps/mm`

当用户选择直接输入换算值时，系统仍保留电机参数和 TMC5240 参数，但机构计算结果以用户输入值为准。

## 9. 运动计算模式

### 9.1 正向运动时间计算

这是最常用的模式。

用户输入：

- 运动距离 `S`
- 最大速度 `Vmax`
- 加速度 `Acc`
- 减速度 `Dec`
- 初速度 `Vstart`，默认 `0`
- 末速度 `Vend`，默认 `0`

系统输出：

- 曲线类型：T 型 / 三角
- 实际峰值速度 `Vpeak`
- 是否达到设定最大速度
- 加速时间
- 匀速时间
- 减速时间
- 总时间
- 加速距离
- 匀速距离
- 减速距离
- TMC5240 参考寄存器值

### 9.2 距离 + 任意两个参数求第三个

工具应支持用户在固定距离下，从以下三个参数中输入任意两个，并求出第三个：

- 最大速度
- 加减速度
- 总时间

说明：

- 当用户输入最大速度和加减速度时，系统计算总时间。
- 当用户输入最大速度和总时间时，系统反推所需加减速度。
- 当用户输入加减速度和总时间时，系统反推所需最大速度。
- 如果加速度和减速度不相等，系统使用加减速比例进行反推。
- 默认加减速比例为 `Acc:Dec = 1:1`。
- 用户可以手动设置加减速比例，例如 `Acc:Dec = 1:2`。

如果反推结果物理上不可行，系统应提示原因，例如：

- 总时间过短，无法在当前速度限制下完成距离。
- 设定最大速度过低，无法在目标时间内完成距离。
- 加减速比例导致减速距离超过总距离。

### 9.2.1 目标时间反推推荐参数

当用户已知运动距离和目标时间时，工具应支持根据策略推荐一组 `Vmax`、`Acc`、`Dec`。

输入：

- 运动距离 `S`
- 目标时间 `Ttarget`
- 推荐策略
- 加减速比例，默认 `Acc:Dec = 1:1`
- 最大速度上限，可选
- 最大加速度上限，可选
- 最大减速度上限，可选

第一版支持的策略：

| 策略 | 说明 |
| --- | --- |
| 平衡策略 | 默认策略，在速度和加速度之间折中 |
| 低冲击策略 | 优先降低加速度，适合皮带、丝杆和较重负载 |
| 低峰值速度策略 | 优先降低 `Vmax`，适合高速能力有限的电机 |
| 对称加减速策略 | 强制 `Acc = Dec`，便于调试和参数理解 |

第一版界面预留但暂不支持的策略：

| 策略 | 显示方式 |
| --- | --- |
| 六点斜坡低冲击策略 | 灰显，标注“待开发” |
| 六点斜坡防失步策略 | 灰显，标注“待开发” |
| 六点斜坡快速节拍策略 | 灰显，标注“待开发” |

第一版输出：

- 推荐 `Vmax`
- 推荐 `Acc`
- 推荐 `Dec`
- 实际总时间
- 曲线类型：T 型 / 三角
- 加速时间、匀速时间、减速时间
- 加速距离、匀速距离、减速距离
- TMC5240 参考寄存器值

### 9.3 T 型三段反推寄存器

此模式来源于用户提供的 Excel `T型斜坡计算` 工作表。

适用场景：

- 用户已知加速段、匀速段、减速段各自的距离和时间。
- 用户希望反推 TMC5240 的 `AMAX`、`VMAX`、`DMAX`。
- 用户希望和当前 Excel 公式逐项对照。

输入层应采用双层显示：

1. 物理单位输入，便于工程使用。
2. 微步、圈数、寄存器单位对照，便于和 Excel 公式、TMC5240 寄存器核对。

用户输入：

- 加速段距离
- 加速段时间
- 匀速段距离或匀速段时间
- 减速段距离
- 减速段时间
- `VSTART` 寄存器值，默认 `0`
- `VSTOP` 寄存器值，默认 `10`

系统输出：

- 加速度 `rps/s`
- 最大转速 `rps`
- 减速度 `rps/s`
- `AMAX`
- `VMAX`
- `DMAX`
- `XTARGET`
- 总微步数
- 总时间
- 分段结果表

## 10. 正向计算公式

以下公式使用物理单位：

- 距离：`mm`
- 速度：`mm/s`
- 加速度：`mm/s²`
- 时间：`s`

### 10.1 默认初末速度为 0 的情况

加速距离：

```text
Sacc = Vmax² / (2 * Acc)
```

减速距离：

```text
Sdec = Vmax² / (2 * Dec)
```

如果：

```text
S >= Sacc + Sdec
```

则使用 T 型曲线：

```text
Tacc = Vmax / Acc
Tdec = Vmax / Dec
Sconst = S - Sacc - Sdec
Tconst = Sconst / Vmax
Ttotal = Tacc + Tconst + Tdec
```

如果：

```text
S < Sacc + Sdec
```

则使用三角速度曲线：

```text
Vpeak = sqrt(2 * S * Acc * Dec / (Acc + Dec))
Tacc = Vpeak / Acc
Tdec = Vpeak / Dec
Tconst = 0
Ttotal = Tacc + Tdec
```

### 10.2 初末速度可修改的情况

当用户修改初速度或末速度时，系统应使用通用公式：

```text
Sacc = (Vpeak² - Vstart²) / (2 * Acc)
Sdec = (Vpeak² - Vend²) / (2 * Dec)
```

若可达到 `Vmax`：

```text
Vpeak = Vmax
Tacc = (Vmax - Vstart) / Acc
Tdec = (Vmax - Vend) / Dec
Tconst = (S - Sacc - Sdec) / Vmax
Ttotal = Tacc + Tconst + Tdec
```

若不可达到 `Vmax`，则求解实际峰值速度：

```text
Vpeak² = (2 * S * Acc * Dec + Dec * Vstart² + Acc * Vend²) / (Acc + Dec)
```

再计算：

```text
Tacc = (Vpeak - Vstart) / Acc
Tdec = (Vpeak - Vend) / Dec
Tconst = 0
Ttotal = Tacc + Tdec
```

系统必须校验：

- `Vpeak >= Vstart`
- `Vpeak >= Vend`
- `Vmax >= Vstart`
- `Vmax >= Vend`

否则该参数组合不可行。

## 11. TMC5240 换算公式

### 11.1 基础参数

电机每圈微步数：

```text
Count = 360 / step_angle * microstep
```

其中：

- `step_angle` 为电机步距角。
- `microstep` 为微步细分。
- `Count` 为电机转一圈所需微步数。

### 11.2 速度寄存器换算

实际转速与速度寄存器之间的换算：

```text
V_REG = rps * Count * 2^24 / fCLK
```

```text
rps = V_REG * fCLK / 2^24 / Count
```

```text
rpm = rps * 60
```

适用寄存器：

- `VSTART`
- `V1`
- `VMAX`
- `VSTOP`

### 11.3 加速度寄存器换算

实际加速度与加减速寄存器之间的换算：

```text
A_REG = a_rps2 * Count * 2^41 / fCLK^2
```

```text
a_rps2 = A_REG * fCLK^2 / 2^41 / Count
```

适用寄存器：

- `A1`
- `AMAX`
- `DMAX`
- `D1`

### 11.4 速度阈值寄存器

速度阈值相关寄存器可参考用户 Excel 中 `主要公式` 的换算方式。

第一版可展示但不强制要求配置：

- `TSTEP`
- `TPWMTHRS`
- `TCOOLTHRS`
- `THIGH`

### 11.5 TMC5240 注意事项

- TMC5240 内部时钟典型值为 `12.5 MHz`。
- 如果使用评估板，常见时钟为 `16 MHz`。
- 时钟频率会影响同一寄存器值对应的实际速度和加速度。
- 业务运动的末速度可以为 `0 mm/s`。
- TMC5240 的 `VSTOP` 寄存器不建议设置为 `0`，建议默认显示为 `10`。

## 12. T 型三段反推公式

以下公式来源于用户提供的 `T型斜坡计算` 工作表，并整理为系统需求。

### 12.1 输入参数

基础参数：

- 电机步距角
- 微步细分
- `Count`
- `fCLK`

三段运动参数：

- 加速阶段行程
- 加速阶段时间
- 匀速阶段行程
- 匀速阶段时间
- 减速阶段行程
- 减速阶段时间

寄存器输入：

- `VSTART`
- `VSTOP`

### 12.2 加速阶段反推

将加速阶段位移换算为转动圈数：

```text
Sacc_rev = Sacc_microsteps / Count
```

将 `VSTART` 换算为实际转速：

```text
VSTART_rps = VSTART * fCLK / 2^24 / Count
```

反推实际加速度：

```text
Acc_rps2 = 2 * (Sacc_rev - VSTART_rps * Tacc) / Tacc²
```

反推最大转速：

```text
VMAX_rps = VSTART_rps + Acc_rps2 * Tacc
```

换算 `AMAX`：

```text
AMAX = Acc_rps2 * Count * 2^41 / fCLK²
```

换算 `VMAX`：

```text
VMAX = VMAX_rps * Count * 2^24 / fCLK
```

### 12.3 匀速阶段计算

已知最大转速和匀速位移，计算匀速时间：

```text
Tconst = Sconst_rev / VMAX_rps
```

已知最大转速和匀速时间，计算匀速位移：

```text
Sconst_rev = VMAX_rps * Tconst
```

系统应允许用户选择：

- 输入匀速距离，计算匀速时间。
- 输入匀速时间，计算匀速距离。

### 12.4 减速阶段反推

将 `VSTOP` 换算为实际转速：

```text
VSTOP_rps = VSTOP * fCLK / 2^24 / Count
```

减速阶段位移换算为圈数：

```text
Sdec_rev = Sdec_microsteps / Count
```

反推减速度：

```text
Dec_rps2 = (VMAX_rps² - VSTOP_rps²) / (2 * Sdec_rev)
```

换算 `DMAX`：

```text
DMAX = Dec_rps2 * Count * 2^41 / fCLK²
```

### 12.5 待确认公式

用户 Excel 中 `T型斜坡计算!H36` 当前公式为：

```text
H36 = E36 * C8
```

其中 `C8` 为时钟频率。该单元格文字描述为“这里圈数对应的位置数”，从单位语义看，疑似应使用 `Count` 而不是 `fCLK`：

```text
位置数 = 圈数 * Count
```
故计算公式需要改为：H36 = E36 * C7

## 13. 用户界面需求

### 13.1 主界面布局

## 15. 输入限制规则

### 15.1 基础输入限制

系统仅做必要的输入限制，避免无效参数进入计算。第一版不设置独立的问题中心或轴级问题标记。

必须限制：

- 距离不能为负。
- 最大速度必须大于 `0`。
- 加速度必须大于 `0`。
- 减速度必须大于 `0`。
- 时间不能为负。
- 微步细分必须为 TMC 支持值。
- 步距角必须大于 `0`。
- 减速比必须大于 `0`。
- 导程、齿距、齿数必须大于 `0`。
- `fCLK` 必须大于 `0`。

### 15.2 运动参数限制

必须限制：

- 初速度不能大于最大速度。
- 末速度不能大于最大速度。
- 三角曲线中实际峰值速度必须大于等于初速度和末速度。
- 匀速阶段时间不能为负。
- 反推模式中三段速度必须连续。

### 15.3 寄存器范围限制

必须限制：

- 寄存器值是否小于 `0`。
- 寄存器值是否超出 TMC5240 对应位宽。
- 换算后取整是否为 `0`。
- `VSTOP` 是否为 `0`，默认仍使用建议值 `10`。

当输入不满足限制时，系统在对应输入项旁以内联文本说明原因，并暂停该行计算。系统不需要在运动轴列表或结果表中维护状态列。

## 18. 验收标准

### 18.1 正向计算验收

必须通过：

- 输入长距离时，系统输出 T 型曲线。
- 输入短距离时，系统自动输出三角曲线。
- 加速度和减速度不相等时，计算结果正确。
- 初速度和末速度为默认 `0` 时，结果符合基础公式。
- 用户修改初速度和末速度后，系统使用通用公式计算。
- 同一轴支持多个距离。
- 每个距离支持多个参数组合。

### 18.2 TMC5240 换算验收

必须通过：

- `step_angle = 1.8`
- `microstep = 256`
- `Count = 51200`
- `fCLK = 16 MHz`

校验：

- 速度寄存器与 `rps/rpm` 换算正确。
- 加速度寄存器与 `rps/s²` 换算正确。
- `MRES` 映射正确。
- `VSTOP=10` 能正确换算为实际转速。

### 18.3 T 型反推验收

使用用户提供的 `T型斜坡计算` 表格作为参考样例：

- 加速段：`4000 microsteps`，`0.05 s`
- 匀速段：`591680 microsteps`
- 减速段：`4000 microsteps`，`0.05 s`
- `VSTART = 0`
- `VSTOP = 10`
- `step_angle = 1.8`
- `microstep = 256`
- `fCLK = 16 MHz`

期望接近：

- `AMAX ≈ 27487.79`
- `VMAX ≈ 167772.16`
- `DMAX ≈ 27487.79`

最终显示寄存器时应取整，并保留原始浮点值用于校验。

### 18.4 导出验收

必须通过：

- 保存项目后重新打开，数据不丢失。
- 导出 Excel 后包含轴参数、输入参数、计算结果和寄存器值。
- 导出的 Excel 可用于工程评审和参数归档。

## 19. 重要假设

- 第一版为桌面工具。
- 第一版默认物理单位为 `mm`、`mm/s`、`mm/s²`。
- 初速度和末速度默认均为 `0`，但允许用户修改。
- 轴参数既支持结构化机械参数输入，也支持直接输入 `microsteps/mm`。
- T 型三段反推模式采用物理单位输入，同时显示微步、圈数和寄存器单位。
- `6点斜坡举例` 暂不纳入第一版。
- TMC5240 EightPoint ramp 不做完整芯片级仿真。
- 用户 Excel 是公式理解和结果校准参考，不是所有单元格都直接照抄实现。

## UI补充说明

修改一下整个软件的界面：

首先，打开软件后的首页需要是项目选择界面。如果没有现有项目，则要求必须新建项目。

新建项目时，需要进行以下操作：
1. 对项目进行命名
2. 选择主控器的主频（12.5MHz 或 16MHz）

新建完项目并确定后，即可进入整个操作界面。

进去以后，在整个界面的左侧（即现在的运动轴和换算结果处），是运动轴的新增和删除区域。这里默认是空白的，可以新增多个运动轴。

点击“新增”后，需要填入运动轴的名称并选择结构类型。结构类型包括以下三种形式：

1. 步进直线运动
   需要输入：步距角、微步、减速比、同步轮齿数、同步轮齿距(单位mm)

2. 步进旋转运动
   需要输入：步距角、减速比、微步。

3. 步进丝杆运动
   需要输入：步距角、丝杆导程（单位mm）、微步。

   
中间这个区域是一个动作计算区域，默认是空白。用户可以新增动作，新增动作是从当前的运动轴中任意选择一个并点击。

选完以后，需要输入以下参数：
1. 速度 Vmax
2. 加速度：一段加速度A1、二段加速度A2、三段加速度AMAX
3. 减速度：一段减速度DMAX、二段减速度D2、三段减速度D1
4. 初始速度VSTART和末速度VSTOP
5. 一段速度阈值V1，二段速度阈值V2
刚刚的 Vmax、123 段加速度、123 段减速度，以及初始速度和末速度，都可以通过以下两种方式输入：
1. 输入寄存器的值
2. 输入真实的物理单位

系统支持这两者之间的自动转换计算。
可以设置两排输入：
1. 第一排是寄存器的值（十进制）
2. 第二排是真实的换算后的物理单位的值（mm/s  mm/s2）
输入任意一个值就可以自动显示对应的另外一个值

输入完成以后，在此状态下允许在下方添加多个距离，系统会根据距离值来换算时间。每一根轴都可以添加多个距离值来显示时间，且每一个距离后面都可以进行备注说明。距离的输入方式可以是寄存器的值（即 X_TARGET），或者是输入毫米。输入任何一个值，系统都可以自动换算另一个值。

然后可以选择这里面的任意一组计算的结果。选择之后，在右侧显示它的计算详情，在底部绘制它的曲线

结果详情里面显示，曲线类型达到 Vmax、Vpeak 值，包含：

1. 总时间（运动的总时间）
   总时间进一步分为：
   (a) 加速时间
   (b) 匀速时间
   (c) 减速时间

2. 运动距离
   分为：
   (a) 加速距离
   (b) 匀速距离
   (c) 减速距离

   下面的波形曲线里面，要把 X 轴的加速时间点和减速时间点都写出，如果是分多段的话，要把多段的时间点画出来；如果是多段加速的话，也要把多段的时间点都要画出来

   Y 轴要画出两个速度切换的阈值点，然后再把峰值速度画出（V1,V2,VMAX和Vpeak （如果T型 VMAX=VPEAK）

目标时间反算（改反推为反酸）的这个地方也是一样：

1. 运动距离
   可以输入物理的毫米单位，或者是输入 X_TARGET 的值，互相之间自动换算。

2. 时间
   默认输入单位是秒。

3. 策略
   策略保持不变，但需要翻译成中文。

4. 运动参数（Vmax、ACC、DCC）
   加速度跟减速度同样可以输入寄存器的值，或者是物理的加速度，互相之间可以换算。
